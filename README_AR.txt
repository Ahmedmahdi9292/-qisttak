قسطتك — النسخة النهائية الجاهزة للمزامنة السحابية

مهم: لا يمكن تشغيل المزامنة بين الأجهزة من GitHub Pages وحده. يجب إنشاء مشروع Supabase واحد وربط بياناته في config.js.

الخطوات:
1) أنشئ مشروع Supabase.
2) من SQL Editor شغّل كامل محتوى SUPABASE_SETUP.sql.
3) من Project Settings > API انسخ Project URL و anon/publishable key.
4) افتح config.js وضع القيم مكان الفراغين.
5) ارفع جميع الملفات إلى GitHub Pages.
6) افتح قسطتك في الجهاز الأول واضغط ☁️ المزامنة وأنشئ حسابًا.
7) افتح نفس الرابط في الجهاز الثاني وسجّل الدخول بنفس الحساب.

بعد ذلك: الزبائن والعقود والمدفوعات والمصاريف تتزامن بين الأجهزة.

لا تشارك Service Role Key. التطبيق يحتاج المفتاح العام/anon فقط مع سياسات RLS الموجودة في SQL.
