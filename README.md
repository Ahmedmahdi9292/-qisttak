# قسطتك (GestTec) — النسخة الأولى
نسخة أولية محلية قابلة للتجربة في المتصفح.

## التشغيل
افتح `index.html` مباشرة في المتصفح. البيانات تحفظ محلياً داخل الجهاز عبر localStorage.

## الحساب
سعر الأساس = سعر الشراء + ربح السلعة
تحميل = سعر الأساس × نسبة التحميل
الإجمالي = سعر الأساس + التحميل
المتبقي بعد المقدم = الإجمالي - المقدم
القسط = المتبقي ÷ عدد الأشهر

النسخة الأولى تشمل: لوحة رئيسية، زبائن، عقد جديد، تسجيل دفعة، جدول أقساط، تأجيل، تسديد مبكر، أرشفة، وبحث.
